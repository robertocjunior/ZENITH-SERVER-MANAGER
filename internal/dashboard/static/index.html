Arquitetura Agentless Protheus

O Zenith Server Manager opera de forma 100% agentless, sem instalar binários ou serviços terceiros dentro do servidor Windows TOTVS Protheus.

• WinRM (HTTP/HTTPS): Telemetria WMI segura com scripts PowerShell parametrizados e sanitizados contra command injection.
• SMB2 (445/TCP): Leitura de console.log e dbaccess.log via stream com controle de offset e backoff exponencial.
• TSDB VictoriaMetrics: Armazenamento de séries temporais de alta densidade e compressão.
